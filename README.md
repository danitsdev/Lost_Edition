# Lost Edition

A massive, fan-made content expansion for Balatro.

Lost Edition is built with love by members of the Balatro modding community. It aims to feel like a natural extension of the base game, with lots of new content to discover and fresh synergies to explore.

## Features
- 80+ new Jokers spread across multiple pages
- 10+ challenging new Boss Blinds
- New Decks, Stakes, Tags, Vouchers, Editions, Enhancements, and Consumables
- New Challenges to test your builds
- Optional themes and color presets
- Original music (toggle between Lost Edition OST and Balatro OST)

## Requirements
Lost Edition requires the following:

- Steamodded ≥ `26.829.0`
- Lovely ≥ `0.9.0`

Mod managers (Thunderstore Mod Manager, r2modman, Gale, Balatro Mod Manager) install these dependencies automatically.

## Installation

### Mod manager (recommended)
1. Install **Lost Edition** using [r2modman](https://github.com/ebkr/r2modmanPlus), [Gale](https://github.com/Kesomannen/gale), Thunderstore Mod Manager, or [Balatro Mod Manager](https://balatro-mod-manager.dasguney.com/).
2. Launch Balatro through the manager and enjoy!

### Manual installation
1. Install the required frameworks ([Steamodded](https://github.com/Steamodded/smods) and [Lovely](https://github.com/ethangreen-dev/lovely-injector)) for Balatro.
2. Download the latest packaged `.zip` from the [Lost Edition Releases page](https://github.com/danitsdev/Lost_Edition/releases/latest).
3. Extract the archive into a `Lost_Edition` folder inside your Balatro mods directory:
   - Windows: `%APPDATA%/Balatro/Mods/Lost_Edition`
4. Launch the game and enjoy!

> [!IMPORTANT]
> Do not use GitHub's **Download ZIP** option on the source/main branch. It may contain work-in-progress files and can break your game. Use a mod manager or the packaged files from the Releases page instead.

## Updating

To update safely:

- Close the game.
- If you installed through a mod manager, update Lost Edition directly from the manager.
- For a manual installation, delete the existing `Lost_Edition` folder from `%APPDATA%/Balatro/Mods`, then repeat the manual installation steps above.

## Uninstall
Delete the `Lost_Edition` folder from your `Mods` directory (or uninstall via your mod manager).

## Troubleshooting
- The game crashes or the mod doesn't load:
	- Verify Steamodded and Lovely meet the minimum versions listed above.
	- Make sure you installed from a mod manager or the Releases page, not a source ZIP.
- Conflicts: If you suspect a mod conflict, try disabling other mods temporarily.
